**Type:** Client project / service website  
**Role:** Full-stack Engineer  
**Focus:** Course presentation · CMS admin · Trial and consultation flow · Website operations

## Overview

Talk915TW introduces online language-learning services to learners in Taiwan. The public website presents courses, teachers, learner stories, enrollment steps, plan information and FAQs, then directs visitors to request a trial lesson or consultation. This case covers the brand's marketing and inquiry website, not the internal learner classroom platform.

## What I built

- A public website that organizes course, teacher, learner-story, enrollment, FAQ and contact information into browsable sections.
- A CMS admin interface for maintaining site sections, course and plan information, FAQs, social links and articles.
- Trial and course-consultation forms, along with admin functions for managing website articles and inquiries.
- A separation between public presentation and content management so routine copy updates can be handled through the admin.

## Technology

Node.js · Express · JavaScript · Tailwind CSS · SQL data access

## Scope and status

The codebase includes an ECPay integration module. Whether live transactions are enabled in production has not been verified, so this case does not present online payment as a completed or shipped feature. Public materials exclude source code, credentials, transaction data and learner personal information.

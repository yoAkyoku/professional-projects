# Talk915TW 線上語言學習服務官網

[English](README.en.md) · [公開網站](https://www.talk915tw.com)

**專案類型：** 客戶專案／服務網站  
**角色：** Full-stack Engineer  
**重點：** 課程內容呈現 · CMS 後台 · 試聽與諮詢流程 · 官網管理

## 專案概覽

Talk915TW 面向台灣學員介紹線上語言學習服務。公開網站整理課程、師資、學員心得、報名步驟、方案資訊與常見問題，並引導訪客提交試聽或課程諮詢需求。本案例描述品牌推廣與諮詢網站，不涵蓋外部學員上課平台的內部功能。

## 我完成的範圍

- 建置公開網站，將課程、師資、學員故事、報名步驟、常見問題與聯絡方式整理成易於瀏覽的頁面。
- 建立 CMS 管理介面，讓營運人員維護網站區塊、課程與方案資訊、常見問題、社群連結及文章。
- 串接試聽與課程諮詢表單，並提供後台管理網站文章與諮詢資料的功能。
- 將前台內容與管理功能分開，讓常見文案更新可由後台處理。

## 技術

Node.js · Express · JavaScript · Tailwind CSS · SQL 資料存取

## 範圍與狀態

程式碼包含綠界付款介接模組；正式環境是否已啟用交易尚未核實，因此本案例不將線上付款描述為已完成或已上線功能。公開展示不包含網站原始碼、帳密、交易資料或學員個資。
